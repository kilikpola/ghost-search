See which public sites a username, email, or phone number is registered on.

Follow linked handles

When following is on, handles that a matched profile links to publicly (for example a GitHub profile's X account) are scanned too. Email is checked against Gravatar and Keybase, the only sites with a genuine public lookup-by-email API; phone numbers aren't checked against anything yet, since no site offers a public lookup-by-phone API.

A matching username isn't proof it's the same person. Compare names, photos and links before drawing conclusions.
